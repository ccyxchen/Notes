# 手机互传文件

## 使用 LocalSend

快点把手机里的照片、大视频传到电脑上，那么不要执着于“挂载磁盘”，直接使用 LocalSend。它是目前全平台开源、无广告、传文件速度最快的神器。
1. 安装：
	• 手机端：在应用商店下载 LocalSend App。
	• Ubuntu 端：在 Ubuntu 软件中心（App Center）搜索 LocalSend 安装，或者直接通过终端安装：
```bash
sudo snap install localsend
```
2. 使用：手机和电脑打开软件（保持在同一 Wi-Fi），它会自动发现对方。手机端选择文件，点击 Ubuntu 电脑的名字，电脑端点“接受”，传输速度直接拉满你的 Wi-Fi 上限，完全没有配对、断流或 Wayland 兼容性烦恼。

## 使用smb

### 在 Ubuntu 上配置 SMB (Samba) 
SMB 协议在局域网内速度极快，且各大 Android 文件管理器（如 Cx 文件管理器、Solid Explorer）都能无缝完美挂载。

1. 安装 Samba
打开 Ubuntu 终端（Ctrl+Alt+T），运行以下命令：
```bash
sudo apt update
sudo apt install samba -y
```
2. 创建要共享的文件夹
你可以共享已有的文件夹，或者新建一个专属共享区（例如在主目录下创建 ubuntu_share）。
3. 修改 Samba 配置文件
备份并编辑配置文件：
```bash
sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.bak
sudo nano /etc/samba/smb.conf
```
滑到文件最底部，添加以下配置（允许读写访问）：
```ini
[Ubuntu_Share]
   comment = Ubuntu Shared Folder
   path = /home/你的用户名/ubuntu_share
   browseable = yes
   read only = no
   guest ok = no
   create mask = 0775
   directory mask = 0775
   valid users = 你的用户名
```
⚠️ 注意：请把 你的用户名 替换为你实际的 Ubuntu 账户名（可在终端输入 whoami 查看），path 也要对应修改。
保存并退出：按下 Ctrl + O 然后回车保存，再按下 Ctrl + X 退出。
4. 设置 SMB 访问密码
为了安全，Samba 需要独立设置一个远程访问密码（可以和你的系统登录密码不同）：
`sudo smbpasswd -a 你的用户名`
输入两次你想设置的共享密码。
5. 重启服务并放行防火墙
```bash
sudo systemctl restart smbd ufw
sudo ufw allow Samba
```

### 手机端连接

1. 查看 Ubuntu 的局域网 IP（在终端输入 ip a 或在网络设置中查看，例如 192.168.0.100）。
2. 打开手机 Cx 文件管理器 -> 网络 -> 添加网络 -> 局域网 (LAN / SMB)。
3. 输入 Ubuntu 的 IP，填入刚刚设置的用户名和 Samba 密码，即可在手机上完美挂载 Ubuntu 磁盘！

> 或者，如果手机自带的文件管理器有网络访问功能，直接通过远程访问挂载smb 文件夹。

## 使用FTP

如果你更倾向于使用 FTP 协议，Ubuntu 上最常用的服务端是 vsftpd。
1. 安装 vsftpd
`sudo apt install vsftpd -y`
2. 修改 FTP 配置文件
`sudo nano /etc/vsftpd.conf`
在文件中找到以下几行，取消它们前面的 # 号注释（或者如果没有就直接加在文件末尾），确保它们处于开启状态：
```ini
local_enable=YES
write_enable=YES
local_umask=022
chroot_local_user=YES
allow_writeable_chroot=YES
utf8_filesystem=YES
```
* write_enable=YES：允许手机向 Ubuntu 写入和上传文件。
* allow_writeable_chroot=YES：防止最新版安全机制导致本地用户登录报错。
*  utf8_filesystem=YES：在 CX 文件管理器挂载 Ubuntu 的 FTP 后出现中文字符乱码，核心原因是 Ubuntu 默认使用 UTF-8 编码，明确声明文件系统使用 UTF-8 编码。

保存并退出（Ctrl+O 回车，Ctrl+X）。
3. 重启服务并放行防火墙
```bash
sudo systemctl restart vsftpd
sudo ufw allow 20/tcp
sudo ufw allow 21/tcp
```

📱 手机端怎么连接？
1. 打开手机文件管理器，选择添加 FTP 服务器。
2. 输入 Ubuntu 的 IP 地址（默认端口为 21）。
3. 用户名和密码直接填写你 Ubuntu 系统的登录账号和密码。
